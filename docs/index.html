快速开始

克隆仓库并在本地预览文档站点

获取文档仓库

站点为纯静态 HTML，无需构建步骤，任意静态服务器均可预览。

# 克隆仓库
git clone https://github.com/XG-cyhilu/XG-STUDIO-DOCS.git
# 进入文档目录并启动本地服务器
cd XG-STUDIO-DOCS/docs
python -m http.server 8080
# 浏览器访问 http://localhost:8080

目录结构

新增文档按项目 / 通用分类落到对应目录，并在首页登记入口。

docs/ ├── index.html # 本站首页 ├── projects/ │ ├── xgstudio-cpp-ui/ │ ├── xgstudio-cpp-core/ │ └── void-craft-launcher/ └── general/ # 通用文档
