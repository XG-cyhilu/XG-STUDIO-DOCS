本站为纯静态页面，没有任何构建步骤。克隆仓库后在 docs 目录启动任意静态服务器即可。

The site is entirely static and requires no build step. Clone the repository and serve the docs folder with any static file server.

git clone https://github.com/XG-cyhilu/XG-STUDIO-DOCS.git
cd XG-STUDIO-DOCS/docs
python -m http.server 8080
