设计与视觉规范Design & Visual System

桌面产品的视觉与交互基线，以 Fluent 2 为准，由 XGStudio-cpp-UI 具体实现。

The visual and interaction baseline for the desktop products, following Fluent 2 and implemented by XGStudio-cpp-UI.

Fluent 2 Token Metrics Type ramp

基本原则Principles

  • 单一底座：尺寸走 Metrics，颜色走 Token，字号走 type ramp；不在业务代码里写裸数字、裸色值与裸字号。
  • Single foundation: sizes come from Metrics, colours from Token and font sizes from the type ramp; business code never hard-codes raw numbers, colours or sizes.
  • 浅色 / 深色对等：两档明暗 × 两套色板（Microsoft / GitHub）都要成立；切换主题时同步系统标题栏明暗，不出现半深半浅的界面。
  • Light and dark parity: both modes across both palettes (Microsoft / GitHub) must hold up; theme switches also update the system title bar so the window is never half dark.
  • 全自绘：界面不含系统控件，几何、描边、阴影与文字都由 Direct2D 绘制，视觉不随系统主题或高对比度设置漂移。
  • Fully self-drawn: no system controls; geometry, strokes, shadows and text are painted by Direct2D, so visuals do not drift with system themes or contrast settings.
  • 可访问性：所有可交互控件可键盘到达，焦点环按 focus-visible 规则显示，文字对比度按 Fluent 的层级关系保证。
  • Accessibility: every interactive control is keyboard reachable, the focus ring follows focus-visible rules, and text contrast follows Fluent's hierarchy.

尺寸与度量Sizing and metrics

Theme::m 承载全部 Fluent 2 度量；修改这里即可整体换皮，不需要逐个控件调整。

Theme::m holds all Fluent 2 metrics; changing them reskins the whole library without touching individual controls.

字段Field 含义Meaning
radiusBtn / radiusInput按钮与输入框圆角Button and input corner radius
radiusCard / radiusPanel卡片与过渡面板圆角Card and panel radius

布局遵循三条规则：W/H > 0 为硬尺寸、< 0 交给内容或容器、Grow 参与主轴剩余空间分配；子项一律夹在容器内容区内；Desired 返回真实内容尺寸，不能返回可用尺寸。

Layout follows three rules: W/H > 0 is a hard size, < 0 delegates to content or container, and Grow distributes slack on the main axis; children are always clamped to the container's content box; Desired returns real content size, never the available size.

色彩Colour

基础色板由四个 Token 起步，其余颜色全部由强调色与明暗派生：

Four base tokens seed the palette; every other colour is derived from the accent and the mode:

Token 语义Meaning
kp卡面 / 控件底色（key surface）Key surface
bj页面背景Page background
xt悬停填充 / 禁用控件底色Hover fill / disabled surface
wz主文字Primary text

强调色默认 #0071EA，可用 SetAccent 覆盖。派生规则固定：悬停提亮 8%、按下压暗 10%；onAccent 按亮度自动取黑或白；accentSoft 为 12% 透明、accentSel 为 18%；二级文字混向背景 45%、三级 65%；描边混向卡面 84%（深色为白色 14%），分隔线为 90%（深色 8%）。

The accent defaults to #0071EA and can be replaced via SetAccent. Derivation is fixed: hover lightens by 8%, press darkens by 10%; onAccent picks black or white from luminance; accentSoft is 12% and accentSel 18%; secondary text mixes 45% toward the background and tertiary 65%; borders mix 84% toward the key surface (14% white in dark mode) and dividers 90% (8% in dark).

交互与动效Interaction and motion

  • 焦点环：控件框外扩 2px 绘制 2px 强调色描边，整棵树绘制完成后叠加，并夹在最近的 Clip 容器内；仅键盘操作时出现。
  • Focus ring: a 2 px accent stroke offset 2 px outside the control bounds, painted after the tree and clipped to the nearest Clip container; it appears only for keyboard interaction.
  • 键盘：Tab 按树序移动焦点，视口外自动滚入最近的 ScrollView；方向键对 Slider 步进 1%（按 Shift 为 10%），F4 / Alt+↓ 展开下拉，Esc 先收起最上层弹层。
  • Keyboard: Tab moves focus in tree order and scrolls the nearest ScrollView when off-screen; arrows step Slider by 1% (10% with Shift), F4 / Alt+↓ opens dropdowns, and Esc dismisses the topmost layer first.
  • 入场动画：单项 252ms，行间错峰 40ms（上限 240ms）；缓动为 cubic-bezier(0.1, 0.9, 0.2, 1)，起步快、收尾慢。
  • Entrance motion: 252 ms per item with a 40 ms stagger (capped at 240 ms); easing is cubic-bezier(0.1, 0.9, 0.2, 1), fast in and slow out.
  • 持续动画：只有 Progress 不确定态这类本身需要持续运动的控件才保持 60fps，其余界面静止时挂起等待消息。
  • Continuous motion: only controls that inherently animate — such as an indeterminate Progress — keep 60 fps; everything else suspends to the message queue when still.

实现约束Implementation constraints

  • 只用 Direct2D 1.0：不依赖 ID2D1Effect、D3D11 设备、Acrylic / Mica；无障碍环境下可回退 WARP 软渲染。
  • Direct2D 1.0 only: no ID2D1Effect, D3D11 device, Acrylic or Mica; WARP software rendering is the fallback.
  • 阴影：4 层缩放的圆角位图叠加，带尺寸取整与最多 64 张的缓存；不是实时高斯模糊。
  • Shadows: four scaled rounded-rect bitmaps with size rounding and a 64-entry cache; not a real-time Gaussian blur.
  • 输入法：文本框必须处理组合串与候选窗定位，组合串在控件内带下划线渲染，光标随组合推进。
  • IME: text boxes must position the composition string and candidate window; composition text is underlined inside the control and the caret advances with it.
  • 文案：遵循 Fluent 内容规范，英文使用句式大小写（sentence case），不靠全大写或感叹号制造强调。
  • Copy: follow Fluent content guidance — sentence case in English, with emphasis carried by wording rather than all caps or exclamation marks.
