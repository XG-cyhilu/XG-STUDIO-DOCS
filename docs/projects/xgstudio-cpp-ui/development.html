目录结构Repository layout

XGStudio-cpp-UI/
├─ include/vcui/          # public headers — the only part consumers need
│  ├─ vcui.h               # single include + Version
│  ├─ Color.h              # color helpers, Tokens / Metrics / Palette / type ramp
│  ├─ Theme.h              # palette + mode + accent
│  ├─ Gfx.h                # drawing context for custom controls
│  ├─ Widget.h             # base class, PaintCtx, hit testing, animation
│  ├─ Layout.h             # Stack / Card / Grid / Absolute / Divider / ScrollView
│  ├─ Controls.h           # 17 controls + feedback layer
│  ├─ Surface.h            # host window: DPI, frame loop, routing, focus, overlays
│  └─ App.h                # AppOptions + CreateAppWindow / CreateAppSurface / RunAppLoop
├─ src/                    # implementation (private)
├─ demo/
│  ├─ frame.cpp            # VCUIFrameDemo: four pages + sub-navigation (README screenshots)
│  ├─ main.cpp             # VCUIDemo: all controls
│  ├─ minimal.cpp          # VCUIMinimal: smallest usable example
│  └─ multiwin.cpp         # VCUIMultiWin: multiple windows, shared loop
├─ tools/layoutcheck.cpp  # headless layout self-check
├─ docs/                  # screenshots used by the README
└─ CMakeLists.txt

公开 APIPublic API

公开面集中在 include/vcui，src/ 不对外。vcui.h 一次性引入全部头文件。

The public surface lives in include/vcui; src/ is private. vcui.h includes everything.

Gfx

自定义控件在 Paint 里通过 PaintCtx 拿到 Gfx、Tokens、Metrics、scale 与 time。绘制方法包括 Clear、FillRect、RoundRect、StrokeRect、Line、Circle、StrokeCircle、Shadow、Text、TextTrim、Glyph、TextW、PushClip/PopClip。

Inside Paint, PaintCtx exposes Gfx, Tokens, Metrics, scale and time. Drawing methods include Clear, FillRect, RoundRect, StrokeRect, Line, Circle, StrokeCircle, Shadow, Text, TextTrim, Glyph, TextW, PushClip/PopClip.

快速开始Quick start

#include <windows.h>
#include <vcui/vcui.h>

int WINAPI wWinMain(HINSTANCE, HINSTANCE, PWSTR, int) {
    return vcui::CreateAppWindow(vcui::AppOptions{
        .Title  = L"My App",
        .Width  = 960,
        .Height = 640,
        .Dark   = false,
        .Build  = [](vcui::Widget& body) {
            auto page = vcui::VBox(14.f);
            page->Pad(24.f);
            page->Add(std::make_shared<vcui::Label>(L"Hello", 20.f, 600));

            auto card = std::make_shared<vcui::Card>();
            card->Add(std::make_shared<vcui::Input>(L"Type something..."));
            card->Add(std::make_shared<vcui::Button>(L"OK", true));
            page->Add(card);

            body.Add(page);
        }
    });
}

cmake --build .build --config Release
选项Option默认Default说明Description
VCUI_BUILD_SHAREDOFF构建 DLL + 导入库Build a DLL plus import library
VCUI_BUILD_DEMOON构建四个示例程序Build the four demo executables
VCUI_STATIC_RUNTIMEOFF/MT，静态链接 MSVC 运行时/MT, static MSVC runtime

集成Integration

add_subdirectory(path/to/XGStudio-cpp-UI)
target_link_libraries(YourApp PRIVATE VCUI::vcui)
cmake --install .build --config Release --prefix path/to/install

find_package(VCUI 1.0 REQUIRED)
target_link_libraries(YourApp PRIVATE VCUI::vcui)
# configure with -DCMAKE_PREFIX_PATH=path/to/install
vcpkg install vcui --overlay-ports=path/to/port

公开头是 UTF-8 with BOM，不加 /utf-8 也能正确解析；用 add_subdirectory 时 /std:c++17 会自动传递给消费方。

Public headers are UTF-8 with BOM and parse correctly without /utf-8; add_subdirectory propagates /std:c++17 to consumers.
