主题如何派生How the theme is derived

只有四个基础色（卡面、页面底色、悬停填充、主文字）来自色板，其余全部由强调色和明暗算出来。这样换一个强调色，整棵控件树的悬停、按下、选中、描边都会一起变。

Only four base colours (surface, page background, hover fill, primary text) come from the palette; everything else is computed from the accent colour and mode. Change one accent and hover, press, selection and border states across the whole tree follow.

Tokens Derive(Tokens t, D2D1_COLOR_F accent) {
    t.accent      = accent;
    t.accentHover = Lighten(accent, .08f);     // 提亮 8%
    t.accentPress = Darken(accent,  .10f);     // 压暗 10%
    t.accentSoft  = A(accent, .12f);           // 选中导航、徽章底
    t.accentSel   = A(accent, .18f);           // 列表行选中底
    t.onAccent    = OnColor(accent);           // 按亮度取黑 / 白

    t.text2  = Mix(t.wz, t.bj, .45f);          // 次级文字
    t.text3  = Mix(t.wz, t.bj, .65f);          // 三级 / 禁用文字
    t.border = Mix(t.wz, t.kp, .84f);          // 控件描边
    return t;
}

排版同理：字号不是一个数字，而是 type ramp 的一档，每档自带字号、字重和绝对行高。因此 32px 标题的行高是 40，而不是 1.55 倍。

Typography works the same way: a size is a type-ramp entry carrying font size, weight and an absolute line height. A 32 px title therefore uses a 40 px line height, not 1.55×.

离屏层渲染Off-screen rendering

所有绘制先落在持久离屏层上，每帧只把整层贴一次到窗口；动画只重绘标脏的控件矩形（含阴影余量），滚动只重绘滚动容器。

All painting lands on a persistent off-screen layer that is blitted to the window once per frame; animations repaint only dirty control rectangles (with shadow margin), and scrolling repaints only the scroll container.

// 有动画时：推进状态 → 只让脏区域进入重绘
void Surface::Tick(float dt) {
    animating_ = root_ ? root_->Update(dt) : false;
    if (animating_) UpdateWindow(hwnd_);
}

// 绘制：整棵树画进离屏层，最后一次性贴到窗口
void Surface::Paint() {
    g_.Clear(theme_.t.bj);          // 页面底色
    root_->Arrange(clientRect_);    // 先布局
    root_->Paint(ctx);              // 全部画进 layer
    g_.Present();                   // layer → hwnd，一次贴图
}
while (animating) {
    root->Update(dt);               // 动画读数（悬停 / 按压 / 入场）
    InvalidateDirtyRect(28.f);      // 脏矩形，留 28px 阴影余量
    UpdateWindow(hwnd);
    DwmFlush();                     // 与桌面合成节拍对齐
}
// 没有动画时挂起在 GetMessage，CPU 归零

由于绘制目标是 ID2D1BitmapRenderTarget，库不需要 D3D11 设备、ID2D1Effect、Acrylic 或 Mica；阴影用四层缩放的圆角位图叠加并缓存，代价是它不是真正的高斯模糊。

Because the target is an ID2D1BitmapRenderTarget, the library needs no D3D11 device, ID2D1Effect, Acrylic or Mica. Shadows are four scaled rounded bitmaps with caching — the trade-off is that they are not true Gaussian blur.

输入法：把组合串放对位置IME: putting composition in place

自绘文本框最容易做残的地方是输入法。这里的做法是接管组合消息，把组合串按光标位置布局，并把系统候选窗锚到光标附近。

IME is where self-drawn text boxes most often break. The approach here is to take over composition messages, lay out the composition string at the caret, and anchor the system candidate window next to it.

case WM_IME_STARTCOMPOSITION: {
    CANDIDATEFORM cf{};
    cf.dwIndex = 0;
    cf.dwStyle = CFS_CANDIDATEPOS;
    cf.ptCurrentPos = CaretPoint();      // 客户区坐标
    ImmSetCandidateWindow(himc, &cf);
    break;
}
case WM_IME_COMPOSITION:
    if (lparam & GCS_COMPSTR) {
        composition = ReadComposition(himc);   // 控件内带下划线渲染
        COMPOSITIONFORM form{};
        form.dwStyle = CFS_POINT;
        form.ptCurrentPos = CaretPoint();
        ImmSetCompositionWindow(himc, &form);
        Invalidate();
    }
    break;

组合串推进时光标跟着走，提交后清空组合态；焦点离开输入框时结束组合，避免候选窗残留在屏幕上。

The caret advances with the composition string and the composition state clears on commit; leaving the field ends composition so no candidate window is left behind.

焦点环为什么只在键盘时出现Why the focus ring is keyboard-only

焦点环在整棵树绘制完成之后叠加，并夹到最近的裁剪容器内；只有键盘操作才进入“键盘焦点模式”，鼠标点击产生的焦点能收键盘事件但不画环。

The focus ring is painted after the tree, clipped to the nearest clipping container. Only keyboard interaction enters keyboard-focus mode: pointer-acquired focus still receives key events but draws no ring.

void PaintFocusRing(Gfx& g, Widget* w, const Tokens& t) {
    D2D1_RECT_F rc = Inflate(w->Frame(), 2.f);   // 框外扩 2px
    g.PushClip(NearestClipAncestor(w));          // 不画到滚动容器之外
    g.StrokeRect(rc, 4.f, t.accent, 2.f);        // 2px 强调色描边
    g.PopClip();
}
// Tab / Shift+Tab 按树序在 Focusable() 控件间移动；
// 焦点落到视口外时，最近的 ScrollView 自动把它滚进来。
