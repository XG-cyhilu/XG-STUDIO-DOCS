这是什么What it is

Void Craft Launcher（VCL）是一个 Minecraft Java 版启动器。它的核心主张不是「功能最多」，而是 目录结构完全兼容：任意一个标准 .minecraft 文件夹都能直接作为 Root 添加， 扫到的版本立刻可启动，也可以和 PCL、官方启动器共用同一个目录。

Void Craft Launcher (VCL) is a Minecraft: Java Edition launcher. Its central claim is not "most features" but full layout compatibility: any standard .minecraft folder can be added as a Root, the versions found there launch immediately, and it can share a folder with PCL or the official launcher.

四条原则决定了它的形态：

Four principles shape it:

  • 不污染游戏目录：除 versions\<name>\.vcl\ 这一个私有元数据目录外，不往 Root 里写东西。
  • No pollution: nothing is written into the Root except one private metadata directory, versions\<name>\.vcl\.
  • 不复制 GPL 实现：只按公开规范（Mojang version json、Fabric meta、Forge installer）实现。
  • No GPL code copied: implementation follows public specifications only (Mojang version json, Fabric meta, Forge installer).
  • 启动与安装外包：classpath 求值、loader 安装、JVM 拉起交给 Rust 库 LightyLauncherLib，VCL 只做外壳、目录、元数据与界面。
  • Delegate launch and install: classpath resolution, loader installation and JVM spawning belong to the Rust library LightyLauncherLib; VCL handles shell, directories, metadata and UI.
  • UI 与业务分离：UI 只读状态、只发 Intent，业务层不依赖 UI，可以命令行跑通。
  • UI/business separation: the UI only reads state and dispatches Intents; the business layer has no UI dependency and runs headless.

界面Interface

界面由 VCUI 承载，规划中的骨架是经典四段结构：

The interface is built on VCUI. The planned skeleton is a conventional four-part structure:

标题栏Title bar自绘、可拖拽、与窗口控件同一套主题Custom-drawn, draggable, sharing the window's theme
侧边导航Side navigation实例、下载、设置等入口，带选中态与图标位Instances, downloads, settings, with selected state and icon slots
内容容器Content host页面栈与切换，页面只读状态Page stack and transitions; pages only read state
状态栏Status bar任务进度、日志入口、当前 RootTask progress, log entry point, current Root

主题方面，跟随 VCUI 的浅色 / 深色双主题、强调色与透明度设置；默认浅色，强调色默认 #0071EA， 透明度先只作用于背景层。窗口尺寸与 DPI 由 app::App 统一处理。

Theming follows VCUI's light/dark pair plus accent colour and opacity settings: light by default, accent #0071EA, with opacity initially applied to the background layer only. Window sizing and DPI are handled centrally by app::App.
